# Guia rapida del operador

Parqueadero Neiva - uso diario.

## Entrada (30 segundos)

1. **Entrada** en el menu.
2. Placa (ej. `ABC-123`) + Categoria + Nombre del cliente.
3. Si tiene el correo del cliente, escribalo (para su portal).
4. **Registrar entrada** -> entregar el **ticket** -> **Aceptar**.

## Salida (30 segundos)

1. **Salida** en el menu.
2. Escriba la placa o el ID de transaccion -> **Buscar**.
3. Revise el **total a pagar**.
4. **Efectivo**: escriba lo recibido (calcula el cambio). Otros metodos: elegir y
   pagar.
5. **Pagar** -> entregar el **recibo**.

## Reglas de cobro

- Primeros **15 minutos**: sin costo.
- Luego: se cobra por **hora completa** (redondeo hacia arriba).
- Tarifa por categoria (A, B, C, D) definida por el administrador.
- Si el cliente tiene **mensualidad**, la salida es $0.
- Si tiene **abono**, se descuenta del saldo (puede pedir pago mixto).

## Activos

**Activos** = vehiculos que estan dentro. Use el buscador por placa.

## Problemas comunes

| Situacion | Que hacer |
|-----------|-----------|
| "Ya tiene una entrada activa" | Buscar la placa en **Activos**; si esta, registrar salida |
| "Formato de placa invalido" | Usar `AAA-123` o `ABC123`; si es extranjera, marcar **Placa internacional** |
| El boton Pagar no responde | Verificar que el monto recibido cubra el total |
| Sesion cerrada | Volver a ingresar con su usuario y contrasena |

## Seguridad

- No comparta su clave. Cierre sesion al terminar el turno.
- No deje la sesion abierta en equipos compartidos.
